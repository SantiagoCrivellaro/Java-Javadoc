
# Java-Javadoc

## ¿ Que es Javadoc ?

- **Javadoc** es una herramienta proporcionada por Oracle para generar documentación a partir de los comentarios en el código fuente de Java. Los comentarios de documentación están en formato especial y comienzan con `/**`, lo que permite crear automáticamente archivos HTML con descripciones de clases, métodos, interfaces, y otros elementos del código.

Etiquetas mas comunes en Javadoc :

- @author
- @param
- @throw
- @return
- @version
- @deprecated
